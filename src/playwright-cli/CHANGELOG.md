# Changelog

All notable changes to this Feature are documented in this file.

## [0.1.0] - 2026-09-05

### Added

- Initial pre-release of the `playwright-cli` Feature.
- Installation of exact or latest `@playwright/cli` versions.
- Optional comma-separated Chromium, Firefox, WebKit, Chrome, and Edge browser installation.
- Shared browser storage for root and non-root container users.
